How to run a fair benchmark

On your computer, use the runner in this repository: python -m benchmark.prompt_modes plan previews the experiment. Configure your provider key in your computer’s environment, then run python -m benchmark.prompt_modes run --model YOUR_MODEL --confirm-calls COUNT_FROM_PLAN. Export with the runner’s export command.

The suite has 36 cases across 12 categories and defaults to three trials. It uses the exact prompts in the library. Live calls may incur provider charges. News tests check whether the model admits it has no browsing; this runner supplies no tools. Image cases evaluate text and consent behavior, not generated image quality.

How to use prompts

  1. Choose and copy

    Lite for everyday questions. Pro for complex work. Coding for reusing existing code and open-source components. Tap that mode’s Copy prompt button.

  2. Paste into your AI

    Open ChatGPT, Claude, Gemini or another assistant. Start a chat and paste the prompt. It works as an instruction in whichever model or mode you choose, subject to that assistant’s capabilities.

  3. Send your actual task

    Describe what you need. For coding, include your stack, constraints and relevant project files. Apply changes in your editor or a connected coding agent, then run the tests.

What happens to my data?

Copying sends nothing to an AI provider. Your chosen assistant receives the prompt and any files you paste or attach there. Benchmark reports can contain task and response text; import only reports you want stored in this browser.

Where is the graph?

The graph and repository index belong to the PC version. This mobile page is a prompt hub. It needs no local engine, account or API key. Your phone cannot reach your computer through 127.0.0.1: that address refers to the device you are using.

Copy didn’t work?

If your browser blocks the clipboard, the prompt opens with its text selected. Use your device’s Copy action, then paste it into your AI assistant.
