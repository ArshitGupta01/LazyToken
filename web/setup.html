BEFORE YOU BEGIN

A few things to know.

01 / RUNTIME

Check your tools

Install Node.js 18+ and Python 3.11+, then reopen your terminal. Run npx toksmart@latest doctor --format text if startup fails.

02 / REPOSITORY

Add your project

After the dashboard opens, run toksmart add /path/to/project in a second terminal. Only the path you choose is indexed.

03 / OTHER PORT

Changed the port?

This page checks port 8765. If you started TokSmart on another port, open the address printed by your terminal directly.
